# 公式推导与代码对应

公式以现存执行语句为准。γ 表示反馈 SNR 的 dB 值，Γ=10^(γ/10) 是线性值；H 是真实 CSI，Ĥ 是重建。以下 Ns 均指阶段 B 的复符号数，除非明确写阶段 A。

## 1. 输入与资源

复数 H∈C^(32×32)，张量 x∈R^(2×32×32)；第 0/1 通道分别存实部/虚部。

阶段 B 的预处理是 `x←x/sqrt(mean(x²))`，再 `x←x/3`。这里 mean 跨全部实通道与空间维，因此不等于强制复数平均功率为 1。只要预测与真值共同乘同一常数，NMSE 的分子分母同比缩放，比例不变；共同加一个平移量一般会改变分母，所以 **NMSE 不具有一般仿射不变性**。

16-QAM 每个复符号有 log₂16=4 个标签位，名义资源 B=4Ns。Ns=16/32/64 对应 64/128/256 个标签位。它不是已实现的净业务比特率：本链路直接输出星座点，没有在此之外实现完整比特编码、CRC 或信道编码。B 也不是香农容量。

代码：`quality_v5.load_split`、`train_rdae.load01`、`model_v4.to_symbols`。

## 2. 有效前缀归一化与实际发射功率

编码器输出 z∈R^128，重排为 64 对 I/Q。对样本 i，m_ik=1[k<Ns_i]。

\[
 E_i=\sum_{k< N_{s,i}}(z_{i,2k}^2+z_{i,2k+1}^2),\qquad
 \widetilde z_i=z_i\sqrt{N_{s,i}/\max(E_i,\epsilon)}.
\]

于是 **量化前有效复符号平均能量**约为 1。接下来对 I/Q 独立量化到 `{−3,−1,1,3}/√10`，记 x_i=Q(ẑ_i)。均匀使用 16 个星座点时平均复功率为 1，但网络产生的占用概率未必均匀，所以量化后必须重新测量：

\[
 P_{tx,i}=\frac{1}{N_{s,i}}\sum_{k<N_{s,i}}|x_{ik}|^2.
\]

训练未标定时用当前样本有效功率确定噪声；评估通常在训练数据上标定 P_ref(Ns,γ) 并冻结。不要拿编码器输出功率替代量化后的 P_tx；这正是早期小增益消失的口径问题。

代码：`normalize_power → qam_map_ste → tx_power → LinkRDAE.calibrate`。阶段 A 为实符号，`Link.forward` 用 batch 的量化后平均功率，噪声没有下面的复数 √2 因子。

## 3. AWGN 噪声怎么从 SNR 得到

复 AWGN n~CN(0,N0)，由 Γ=P_ref/N0 得

\[
 N_0=P_{ref}10^{-\gamma/10},\quad
 \sigma=\sqrt{P_{ref}}10^{-\gamma/20},\quad
 n_I,n_Q\sim\mathcal N(0,\sigma^2/2).
\]

因此代码对每个实维生成 `randn * sigma/sqrt(2)`。漏掉 √2 会让总噪声能量变成两倍，即有效反馈 SNR 低约 3.01 dB。实际接收向量 y=(x+n)⊙mask，未发送槽位补零。

AF 输入 r=10^(−γ/20)，不是 γ 本身；`AF(x,r)=x⊙sigmoid(W₂ ReLU(W₁[GAP(x);r]+b₁)+b₂)`。编码器与解码器均可用它调节特征，但不能因此认定已经完全消除共享代价。

代码：`model_v4.add_noise`、`model_rdae.AFModule/LinkRDAE.forward`。

## 4. 为什么有限星座还可以联合训练

硬量化 Q 的普通导数几乎处处为 0。阶段 B 用 STE：

\[
 Q_{STE}(z)=z+\operatorname{stopgrad}(Q(z)-z).
\]

前向值严格等于 Q(z)，反向近似 ∂Q_STE/∂z=1。它是有偏代理梯度，不是证明量化真实可导；前向始终有限星座，不是训练时偷偷发连续值。阶段 A 对可学习实星座写成 `hard + (z-z.detach())`，同时给选中的星座点与编码器梯度。

主链路训练目标为

\[
 \min_{\theta,\phi}\;\mathbb E_{H,\gamma,N_s,n}
 \|D_\phi(C_\gamma(Q_{STE}(N(E_\theta(H,\gamma),N_s))),\gamma)-H\|_2^2.
\]

N 是有效前缀归一化，C 是模拟信道。一次 loss.backward() 更新 θ、φ；固定 QAM 与随机信道本身没有可训练参数。BN 的 running_mean/var 是缓冲状态，更新规则不同于优化器梯度更新。演示脚本 `--grad` 只计算梯度、不调用 optimizer.step()。

代码：`train_rdae.train`、`model_v4.qam_map_ste`。

## 5. 蒸馏为什么可能只改变权衡

阶段 A 的学生均为条件共享模型。令重建项 L_rec=||Ĥ_s−H||²；锚点蒸馏为

\[
 L=L_{rec}+\lambda\,1_{anchor}\|\widehat H_s-\operatorname{stopgrad}(\widehat H_T)\|^2.
\]

E3b 对照只改锚点重建权重 w(0/10/20)=3/1/1。它区分“教师输出的作用”和“多给低 SNR 权重的作用”。不同 SNR 共享容量与训练预算，低点变好可能伴随高点变差；不能只报最有利的 0 dB。学生/教师噪声独立，这是实现事实而非相同 y 下的教师监督。

代码：`distill.MixSampler/train`。

## 6. BN 失配与重标定

训练态：BN 用当前 batch 的均值/方差；测试态：用保存的 running_mean/running_var。

\[
 BN(a)=\eta\frac{a-\mu}{\sqrt{v+\epsilon}}+\beta.
\]

设条件 c=(γ,Ns)，混合分布满足

\[
 \mu_{mix}=\mathbb E_c\mu_c,\qquad
 v_{mix}=\mathbb E_c[v_c]+\operatorname{Var}_c(\mu_c).
\]

部署在固定 c 时，混合统计量未必适合。每 batch 条件单一与每样本混合会产生不同 batch 统计量；Ns 的截断补零也会改分布。**用了 BN 不意味着一定失配**，不含 BN 的网络也不能由这个机制推断。

重标定做法：冻结权重，重置 decoder BN 的 running stats，momentum=None，源域训练数据完整跑一遍。这里是逐 batch 累计统计；不是把所有层的部署总体矩精确算出来，尤其有多层 BN、末 batch 较小时。样本少会引入估计噪声，因此早期 40 batch 的结论有被后续整集重做替代的版本。

代码：`extra_experiments/common.recalibrate`；S1 的混合 Ns 协议差异见 08。

## 7. 两端锚点、二阶矩和保守适配

已知 Ns，保存 0/20 dB 条件统计量。t=clip(γ/20,0,1)，可插值均值和方差，也可插值均值与二阶矩 q=v+μ²；两种定义不能混写。对二阶矩方案：

\[
 \mu_t=(1-t)\mu_0+t\mu_{20},\quad
 q_t=(1-t)q_0+tq_{20},\quad v_t=\max(q_t-\mu_t^2,\epsilon).
\]

这是经验近似，不保证中间 SNR 真正激活分布线性变化。本项目在已有长度与 5/10/15 dB 上检验了它，没有证明适配任意长度/场景。

若估计 SNR 不准，对原状态 (μ_base,v_base) 与候选状态 (μ_c,v_c) 保守混合：

\[
 \mu_\alpha=(1-\alpha)\mu_{base}+\alpha\mu_c,\quad
 q_\alpha=(1-\alpha)(v_{base}+\mu_{base}^2)+\alpha(v_c+\mu_c^2),
 \quad v_\alpha=\max(q_\alpha-\mu_\alpha^2,\epsilon).
\]

α 用训练/验证固定，不在 test 逐点挑；运行时无需新一轮梯度训练。但仍需原来的校准资料，也未实现真实 SNR 估计器。

代码：`q1_anchor_stats.py`、`run_uncertainty.blend/select`。

## 8. 质量头在学什么，BS 运行时有没有偷看真值

逐样本标签

\[
 \ell_i=10\log_{10}\left(\frac{\|\widehat H_i-H_i\|^2}{\|H_i\|^2}+\epsilon\right).
\]

输入 u_i=[pool₂×₂(f_i),γ_i/20,Ns_i/64]，共 64+2 维，回归 a_ω(u)≈ℓ。H 只用于离线生成标签和最终评价，运行时不进 a_ω。特征 f 是解码器 y 的确定性函数，并未增加观测信息。

BS 最优平方损失回归对应条件均值 E[ℓ|y,条件]；不同 H 可能映射到近似 y，BS 不一定精确知道每个样本误差。UE 代理有 H，却没有本次 n；两端不构成普遍的“谁信息更多”结论。本项目条件下 UE 代理总体更准，要如实报告。

旧免训练方案 s_res=||F(Ĥ)−y||²：F 是已知发送映射，BS 本地重编码计算，不是真实再次传输。残差小也不保证 H 重建正确。

代码：`q2_quality_networks.cache/fit`、`quality_v5.q2_reencode`。

## 9. 质量差门控与“值得处理”不是同一个目标

两种门限要分清：T_bad 是验证集真误差的 80% 分位数，用于定义越限事件；τ_gate 是验证集预测分数的 80% 分位数，用于决定启动。运行时 a(u)>τ_gate 即调用精修，越限事件 1[ℓ>T_bad] 只在有真值评价时计算。

设精修后为 Ĥ'=Ĥ+R_ψ(Ĥ,f,y,γ)，动作收益 Δ_i=ℓ_i−ℓ'_i。ℓ_i 大不意味着 Δ_i 大；差样本可能难以通过该动作改善。精修器训练需要 H；运行时只做前向，不用 H、不重新发送。

若实际门控率为 p，精修成本 C_r、监测成本 C_m，则随机方案可按 r=min(1,p+C_m/C_r) 的概率调用精修，以匹配额外 MAC。随机损失期望为 (1−r)ℓ+rℓ'；门控方案逐条按动作切换。平均误差、越限率与吞吐是不同目标，某项变好不能替代另一个。

固定门限只控制长期约 20%，不是保证每个在线时隙恰好 20%；离线池严格 top20% 是另一个预算诊断。

代码：`run_followup.output/train_one/policies`。

## 10. 重复发送为什么最多只有“降噪”作用

同一个符号 x 独立重复一次，y₁=x+n₁，y₂=x+n₂。平均后

\[
 \bar y=x+(n_1+n_2)/2,\quad \mathbb E|\bar n|^2=N_0/2.
\]

因此理想等功率独立重复给约 3.01 dB 接收 SNR 改善，却不会增加原编码器的信源描述长度。重复难以弥补已被压缩丢失的信息。本实验仍用原 SNR 特征解码平均后的 y，未同时优化解码条件；更不等同完整 HARQ。

UE 预检实验先用固定代理门限去掉预计最差约 20%，在同一通过集合内比较 BS 与随机选择追加。被排除者的回退、时延、信道老化尚未建模；不能把通过者的风险改善冒充所有 UE 的系统收益。

## 11. 方差分解能说什么，不能说什么

令 L=L(H,n) 为逐样本损失：

\[
 \operatorname{Var}(L)=\operatorname{Var}_H(\mathbb E_n[L|H])+
 \mathbb E_H[\operatorname{Var}_n(L|H)].
\]

第二项是同一 H 不同反馈噪声引起的损失波动。它不等于把 MSE 严格分为“信源误差+信道误差”；噪声波动占比低也不代表加噪没有平均损害，更不能直接推出 BS 监测无价值。

## 12. 两种 NMSE、SGCS 与统计单位

设 r_i=||Ĥ_i−H_i||²/||H_i||²：

\[
 A=10\log_{10}(\operatorname{mean}_i r_i),\qquad
 B=\operatorname{mean}_i10\log_{10}(r_i).
\]

由 Jensen 不等式 B≤A。它们都可用，但不能混在一张无说明的对比表里。阶段 A 主结果是 A，后期质量/精修主要是 B。

对空—频域矩阵每个子载波 k，平方 SGCS 为

\[
 \frac1{N_c}\sum_k\frac{|h_k^H\widehat h_k|^2}
 {\|h_k\|^2\|\widehat h_k\|^2+\epsilon}.
\]

`quality_v5.sgcs_per` 与 `eval_v2.sgcs_sq` 是此平方定义；旧 `model_jscm.sgcs` 不平方。`model_v4.sgcs` 还做了额外 FFT，输入域假设不同；不能不核对就合并它的数值。

三组噪声属于同一个 H 的重复测量；置信区间按 H 聚类。三个独立训练种子的均值±标准差与配对 bootstrap 区间是两种不同统计量。已经多次使用过的 test H 不应再称整个研究从未看过的外部确认集。
