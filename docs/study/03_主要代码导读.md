# 主要代码导读

点击函数链接可打开本仓库源码，括号内保留历史行号供定位。整理时更正了少量说明，细节见 ../PACKAGING.md。先读阶段 B 的主链路，再回看阶段 A 的共享代价。

## A. 数据和链路：第一遍必须读

1. [channel_data.py · gen_one（L26）](../../simulation/channel_data.py#L26)：确认复信道来自哪里，返回 `(2,32,32)`。再看 [quality_v5.py · load_split（L25）](../../simulation/quality_v5.py#L25) 的实数 RMS 归一化与 [train_rdae.py · load01（L33）](../../simulation/train_rdae.py#L33) 的 `/3.0`。函数名 load01 不代表真的变成 [0,1]。
2. [model_rdae.py · LinkRDAE（L94）](../../simulation/model_rdae.py#L94)：从构造函数确认主实验 `cond=False`。这只是不额外拼接条件标量，**不是关闭 AF**。
3. [model_rdae.py · LinkRDAE.forward（L104）](../../simulation/model_rdae.py#L104)：逐行追踪下面的尺寸表。
4. 依次看 [model_v4.py · normalize_power（L83）](../../simulation/model_v4.py#L83)、[model_v4.py · qam_map_ste（L55）](../../simulation/model_v4.py#L55)、[model_v4.py · add_noise（L108）](../../simulation/model_v4.py#L108)、[model_v4.py · pair_mask（L63）](../../simulation/model_v4.py#L63)。
5. 回到 [model_rdae.py · calibrate（L134）](../../simulation/model_rdae.py#L134) 和 [model_rdae.py · p_ref_of（L174）](../../simulation/model_rdae.py#L174)：训练时功率与评估冻结功率分别从哪来。

| 变量/步骤 | 形状（batch=b） | 在代码里确认什么 |
|---|---|---|
| x | b×2×32×32 | 实部/虚部为两个通道；阶段 B 已除以 3 |
| snr_db / ns | b / b | 条件可以逐样本不同 |
| feat | b×1 | `10**(-snr_db/20)`，是幅度比 |
| enc(x,feat) | b×128 | 64 个复符号对应 128 实维；tanh 输出 |
| normalize_power | b×128 | 只用前 Ns 个复符号求有效能量；返回值尾部不一定已置零 |
| to_symbols + QAM | b×64×2 | 最后一维是 I/Q；固定有限电平 |
| noisy | b×64×2 | 只在有效位置加噪；尾部数值不算发射 |
| y=from_symbols×mask | b×128 | 未发送位置在这里归零 |
| dec(y,feat) | b×2×32×32 | 完成基础重建 Ĥ |

代码内部会算尾部 QAM 值；它们不参与有效功率，也不通过反馈链路，接收端由 mask 清零。因此不要把中间张量的 64 个槽位都当成真的发送。

## B. 网络结构与“联合训练”

- [model_rdae.py · EncoderRDAE（L50）](../../simulation/model_rdae.py#L50)：两组 Conv7×7→BN→LeakyReLU→AF，展平后 FC→tanh，2048→128。
- [model_rdae.py · DecoderRDAE（L77）](../../simulation/model_rdae.py#L77)：FC→2×32×32→AF，Conv/BN/sigmoid/AF，再接 5 个残差块。
- [model_rdae.py · _ResBlock（L63）](../../simulation/model_rdae.py#L63)：2→8（7×7）→16（5×5）→2（3×3），各层带 AF，最后残差相加。
- [model_rdae.py · AFModule（L26）](../../simulation/model_rdae.py#L26)：全局池化特征与相对噪声幅度拼接，MLP 生成通道门控。
- [train_rdae.py · train（L42）](../../simulation/train_rdae.py#L42)：`loss = MSE(net(xb,snr,ns),xb)`，`opt` 接收整个 `net.parameters()`，一遍 backward 更新两端。固定 QAM 通过 STE 让梯度继续到编码器。

**现存训练入口**：SNR 默认逐样本从 0–20 dB 抽；Ns 从 16/32/64 **每 batch 抽一个**。参数 `--snr-mode batch` 只改变 SNR 抽样。历史记录“Ns 逐样本抽”不能由该代码支持，旧权重当时使用的精确版本还需训练时源码/日志核实。

## C. 阶段 A：共享模型、专用模型和蒸馏

- [model_jscm.py · Link（L142）](../../simulation/model_jscm.py#L142)：64 实符号链路；`modulate` 学习实数点集，`receive` 区分硬判决与软信息直通。
- [run_experiments.py · train_one（L58）](../../simulation/run_experiments.py#L58)：shared、固定 SNR 专用、带 `_ps` 的逐样本 SNR 对照。先看 scheme 解析，避免以为每个名字是不同架构。
- [eval_v2.py · sgcs_sq（L27）](../../simulation/eval_v2.py#L27)：阶段 A 后续平方 SGCS 评价；不要再沿用 `model_jscm.sgcs` 的旧非平方量。
- [distill.py · MixSampler（L30）](../../simulation/distill.py#L30)：一半 batch 为 0/10/20 dB 锚点，一半在 [0,20] 均匀抽。
- [distill.py · train（L73）](../../simulation/distill.py#L73)：E3a 重建；E3b 锚点重建权重 3:1:1；E4 锚点 batch 加教师输出 MSE，teacher 不反传。三个学生都是条件共享结构。

教师与学生各自调用带噪 forward，噪声不是同一个 y。不要把这里讲成“同一观测下模仿教师”。对照是 E3a，不能拿普通共享模型的 0.69 dB 缺口直接减去蒸馏改善量。

## D. Q1：BN、稀疏锚点、估计条件不准

先读 [bn_v5.py · recalibrate（L30）](../../simulation/bn_v5.py#L30)，再读 [common.py · recalibrate（L63）](../../experiments/extra_experiments_20261113/common.py#L63)。它们把接收端 BN 设为训练态，重置 running stats，用源域训练 H 重新跑一遍，最后切回 eval；不更新可训练权重。

对照含义：S0=原状态；S1=混合条件重统计；S2=目标部署条件重统计。后期 common 的 S1 同时逐样本混合 SNR 与 Ns，现存训练入口却是 batch 固定 Ns，因此 S1 不严格等于原训练协议的纯重复估计。

接着读 [q1_anchor_stats.py](../../experiments/deployment_followup_20261113/q1_anchor_stats.py)：每个已知 Ns 只保存 0/20 dB 两组统计量，中间 SNR 插值；对照直接在目标点重标定。最后读 [run_uncertainty.py · blend（L60）](../../experiments/q1_snr_uncertainty_20261114/run_uncertainty.py#L60) 与同文件 `locked_protocol/select/run`：只改变接收端收到的估计 SNR，保持发送端与 y 不变，按验证集锁定 α，再测保守混合统计量。

## E. Q2：质量头与 UE 代理

先看 [q2_quality_networks.py · cache（L33）](../../experiments/extra_experiments_20261113/q2_quality_networks.py#L33)：hook 抓解码器输入 y（128维），以及最后残差块 af2 的 16 通道特征，池化到 2×2 后得 64 维。`condition=[SNR/20,Ns/64]`。

然后读同文件 `inputs → fit → predict`：约 2.5 万参数 MLP，比较 y+条件、特征+条件、两者+条件；标签是逐样本 NMSE_dB；输入和标签标准化只由训练集拟合。主链路冻结，小质量头单独训练。

[run_cooperative.py · bs_inputs（L104）](../../experiments/two_sided_experiments_20261113/run_cooperative.py#L104) 是后续 feature+condition 质量头的入口；[run_single_pass.py](../../experiments/guo_proxy_experiments_20261113/run_single_pass.py) 是 UE 单次代理对照。UE 用 H 和发送前干净码字，BS 用收到的 y 及其特征；这是 Guo 思路的本项目实现，不是官方论文精确复现。

免训练残差在 [quality_v5.py · q2_reencode（L127）](../../simulation/quality_v5.py#L127)：F(Ĥ) 在 BS 本地算，再与 y 比较；**没有真的让 BS 再向 UE 发一遍**。该方法需要在 BS 存编码器，且不是后期学习型质量头。

## F. Q2：精修、重复、联合维护

**当前精修主版本**：[run_followup.py · Refiner（L32）](../../experiments/q2_refinement_followup_20261113/run_followup.py#L32)，不是更早 1594 参数版。`decode_maps` 把基础重建 2 通道与 16 通道中间特征拼接；归一化后加入两张条件图得 20 通道；y 投影为 4 张图，再拼为 24 通道，Conv24→16→16→2 输出残差。原重建加残差得新重建。看同文件 `output → train_one → policies`，确认：训练是逐样本 NMSE_dB 目标，门控不读取真实误差，随机对照匹配监测开销后的 MAC。

**UE 预检后重复**：[run_screen_retry.py · eligible（L42）](../../experiments/q2_ue_screen_bs_retry_20261113/run_screen_retry.py#L42) 固定 UE 通过集合；`bs_x/ue_x` 指定双方可见信息；`rank_weights/evaluate` 在同一通过者、同一重复次数下比较 BS 与随机。按质量差选是风险目标，按预测收益选是平均 NMSE 目标，不能把两条策略的最佳数字拼成一个方法。

**连接 Q1 与 Q2**：[run_joint.py · run（L226）](../../experiments/joint_receiver_maintenance_20261113/run_joint.py#L226)，从相同 y 出发，只改接收机 BN；旧监测器/旧门限/更新模块分别评估。`update_monitor/update_refiner` 是有标签训练数据上的离线更新，不是在真实 BS 上凭空得到 H 在线训练。
