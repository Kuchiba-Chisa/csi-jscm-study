# 这份 GitHub 整理版改了什么

本版将代码、结果和学习材料复制到独立目录，没有移动或覆盖原始科研文件，也没有重新筛选实验超参数。

## 保留

- 两阶段核心模型、数据生成器、训练和评估入口。
- Q1/Q2 的主要实验代码、前序依赖、负结果、报告及 JSON。
- 最新三种子 BN/GN 对照和单种子 RD-AE 专用/蒸馏补充，分别注明证据强度。
- 代码导读、公式及结果台账。局部源码链接改为本仓库可打开的相对链接。

## 整理性修改

- 本机源目录改为从脚本位置解析 `simulation/`，实验间保留相邻目录关系。
- 运行入口将代码暂存至被忽略的 `runs/`，防止训练覆盖已提交结果。
- 元数据中的本机路径替换为通用相对标识；JSON 中的数字与数值数组不变。
- 更正少数文件头的已知不准确说明。模型计算、网络结构与训练函数不因此改变。
- 新增依赖说明、无权重检查、结果读取器及 GitHub Actions 配置。

`source_manifest.json`保存每个复制文件的原始 SHA256 和整理后 SHA256。`export_changes.json`列出变动文件。原记录的 `script_sha256`或审计 PASS 描述的是历史运行，不是本次新脚本；改变路径或文档后，代码哈希理应不同。

2026-11-16 补充整理清单为 `update_manifest_20261116.json`，覆盖新增的微调、长度采样、CNN输出校准、GN共享代价与GN输出校准。仅重定位本机路径、调整结果导航及运行入口；模型计算与已保存结果的数字不变。绘图脚本改为按字体名称查找，避免依赖特定 Windows 字体文件。历史报告中的“未测GN”等措辞按该报告当时的实验范围理解，新实验另列。

## 不放入仓库的文件

虚拟环境、原始数据、模型权重、逐样本大缓存、远程登录脚本和日志、论文 PDF、任务书、校徽模板及答辩 PPT。本地学习材料和科研原件仍在原位置。

原始旧 `results.json`与已作废 RD-AE 结果不作为主表发布；README 中也不沿用旧 +0.18 dB 星座优势、完整 SSCC 基线或“没有任何研究做过监测”等主张。
