# GN 共享代价补充实验

本轮只回答一个问题：**固定反馈长度 Ns=64，在没有 BN 冻结统计量、共享模型逐样本抽取 SNR 的情况下，共享模型是否仍比同结构专用模型差？**

## 为什么重新训练共享模型

历史 GN 模型同时支持 Ns=16/32/64，不能与此次固定 Ns 的专用模型直接比较，否则会混合跨 SNR 与跨长度两个因素。本轮重新训练一个固定长度共享模型及三个固定 SNR 专用模型。旧权重保持不变。

## 锁定的对照

| 项目 | 共享 | 专用 |
|---|---|---|
| 骨干 | RD-AE 改编，全部 18 层 BN 换 GN | 完全相同 |
| 调制与长度 | 固定 16-QAM、64 个复符号 | 完全相同 |
| SNR | 每个样本独立抽 U(0,20) dB | 分别固定 0/10/20 dB |
| AF 条件输入 | 两端使用 SNR 特征 | 同样使用 |
| 初始化、H 顺序、标准噪声 | 配对固定 | 完全相同的配对序列 |
| 训练 | Adam 2e-3、wd1e-5、cosine40，40轮最终权重 | 完全相同 |
| 选择 | 不按验证/测试结果选轮次 | 完全相同 |
| 评价 | 训练集标定实际发射功率，测试同一1000H×3次标准噪声 | 同口径，各自模型功率 |

一个模型553982参数，FP32有效权重约2.11MiB；三个专用模型约6.34MiB，不含文件封装。每个模型训练轮数相同，专用库总训练量是共享模型的三倍；不声称固定总训练算力下最优。

## 输出与解释

最终查看 `结果说明.md` 和 `results.json`。`progress.json` 是运行状态，`run.log` 每五轮打印一次。

NMSE 差距定义为 **共享减专用**。SGCS 差距定义为 **专用减共享**。两者正数均表示共享较差。只有三个SNR锚点，不推断完整0–20dB曲线。

可能出现共享较好、相近或较差，均原样报告。若GN下仍有差距，只能说明BN冻结统计量失配不是产生差距的必要条件。不能据此把差距认定为容量上限或共享的必然代价。

本次只有一个训练种子。测试H的配对bootstrap区间只描述这组已训练模型在测试H上的波动，不能代替多次训练稳定性验证。没有与完全相同新协议下的BN模型配对重训，不计算BN→GN的共享代价变化量。

合成CSI、AWGN、完美UE CSI；不是完整官方RD-JSCC，不含VQ与扩散，也没有下游吞吐实验。历史测试集已被使用，新噪声不等于独立外部复现。
