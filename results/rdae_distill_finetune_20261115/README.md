# 从共享模型开始的蒸馏微调

本轮补充固定反馈长度的 RD-AE 实验：已有共享模型是否可以通过专用教师蒸馏微调进一步改善？

先读 `微调实验结果.md`，再看 `finetune_comparison.png`。`results.json` 保留全部 SNR 结果，`test_arrays.npz` 保留逐样本、逐噪声误差及 SGCS。

## 对照

同一个训练40轮的共享模型作为起点：

- 原共享模型：不更新。
- 普通微调：额外10轮，仅使用真实CSI重建损失。
- 蒸馏微调：相同额外10轮，锚点batch加入专用教师输出MSE，λ=1。

不改变网络结构和发送符号预算。普通微调与蒸馏微调重置相同规则的优化器，使用相同训练样本顺序、SNR和标准高斯噪声。两端参数均更新，教师冻结。蒸馏需要额外教师前向，因此相同轮数不等于相同训练计算量。

主结果取固定第10轮；验证选轮结果作为补充，允许不更新的epoch0。原来的“从零蒸馏”实验与本轮不能混称。

## 文件

- `protocol.json`：训练前锁定的配置、原文件哈希。
- `run_finetune.py`：本轮训练、评估与报告脚本。
- `trace_continue.json`、`trace_distill.json`：逐轮训练与验证轨迹。
- `continue_final.pt`、`distill_final.pt`：固定第10轮模型。
- `continue_best.pt`、`distill_best.pt`：验证集选出的模型。
- `audit.json`：原检查点、教师和数据未改变；原共享测试结果复现；指标复算。
- `audit_finetune.py`、`independent_audit.json`：重新加载输出模型，对测试集锚点条件重放前向，核对验证选轮和参数更新。

## 解释范围

一个基础模型/教师训练种子；同一历史测试信源集合；三次噪声不能替代独立训练种子。按H配对区间仅描述固定模型下的测试样本不确定性。本轮λ与学习率均事前固定，不根据测试搜索。
